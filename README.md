# 数学物理方法 · 理解、记忆与解题

面向考试复习的中文静态学习网站，按姜颖《数学物理方法》（科学出版社，ISBN 978-7-03-057435-0）组织。

**网站入口：** [数学物理方法复习](https://yizhouren0622-create.github.io/math-physics-review/)

## 已包含的内容

- 六章、38 组知识点：公式、使用条件、可展开的证明或推导、简单例题与记忆线索。
- 全书 126 道主编号书后题：题内小问保留；每题包含提示、思路、解答过程、答案、答题套路和易错点。
- 三套自编模拟卷，各 100 分，含提示、详细解答、评分要点、计时与自评。
- 题号与关键词搜索、待复习清单、笔记、记忆回顾、学习记录导入导出。
- 资料来源与勘误说明，包括缺失条件、主值积分、谱问题反例和变换规范差异。

## 复习方式

先读知识点并自己复述证明，再独立做例题与课后题。卡住时先展开提示，完成后核对步骤，把仍不熟的题标为“需要复习”。最后用模拟卷限时检验。

学习记录只存于当前浏览器，换设备前请在“记忆与回顾”页导出备份。网站无需登录，公式已预渲染为 MathML，运行时不依赖 CDN。下载仓库后可直接打开 `index.html` 离线阅读。

## 来源与核对范围

知识解释、解析与模拟卷独立编写。已读取“上大老姜”公开分享的第二、四章参考答案图片，发现的差异写入对应题目。第一、三、五章仅定位到公开来源链接，图片正文未能读取；第六章未找到可读取的对应答案。不能将这些章节的解答视为已由教师核验。完整链接及读取状态见 [资料与勘误](https://yizhouren0622-create.github.io/math-physics-review/sources.html) 和 `data/sources.json`。

仓库包含学习网站及原创解析，不包含教材 PDF 或整套教师答案原图。内容为第一版独立解析，后续修订应保留题号、具体错误与修正理由。

## 修改与构建

日常内容在 `data/ch1.json` 至 `data/ch6.json`、`data/exams.json` 中维护，段落使用 Markdown，公式使用 `$...$` 或 `$$...$$`。标题使用普通文字与 Unicode 数学符号。

```sh
python3 -m pip install -r requirements-build.txt
python3 build.py
python3 validate.py
python3 -m http.server 8000
```

构建生成根目录 HTML 与 `assets/index-data.js`。GitHub Pages 从 `main` 分支根目录发布，提交内容或样式更新后需一并提交重新生成的页面。`validate.py` 检查全书题号清单、必填解答字段、模拟卷分数及本地链接；它不能代替数学内容校核。
