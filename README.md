## 阅读与入门

- 默认 22px 正文与高对比配色，可选 26px、30px 及柔和配色；手机保持同样字号。
- 每页可切换中文、English、中英对照；语言、字号、对比度自动保存，学习记录继续兼容原版本。
- “从这里开始”包含先修知识、六项基础短练习与自测，以及 38 张知识卡的日常语言解释。相关题目可直接跳到需要补习的基础运算。
- 126 道课后题均有“带我一步一步做”：目标、选方法的线索、5–9 步具体操作、小自测及答案；每次只显示当前一步，也可展开全部。完整证明、解答和分题条件保留。
- 英文覆盖所有知识卡、126 题完整解析、三套模拟卷、来源说明与界面；中英文关键词都可搜索。

## 复习方式

基础薄弱时先打开“从这里开始”，认清符号。知识卡先读白话解释，习题先看“要做什么”和“为什么用这个方法”，再按分步引导自己补算。熟悉以后独立做例题与课后题。卡住时先展开提示，完成后核对步骤，把仍不熟的题标为“需要复习”。最后用模拟卷限时检验。

学习记录只存于当前浏览器，换设备前请在“记忆与回顾”页导出备份。网站无需登录，公式已预渲染为 MathML，运行时不依赖 CDN。下载仓库后可直接打开 `index.html` 离线阅读。

## 修改与构建

构建要求 Python 3.12 或更高版本。中文日常内容在 `data/ch1.json` 至 `data/ch6.json`、`data/exams.json` 中维护，段落使用 Markdown，公式使用 `$...$` 或 `$$...$$`。标题使用普通文字与 Unicode 数学符号。英文对应内容在 `data/en/`，逐题入门引导在 `data/learn/`；同步修改两种语言。`data/introductions.json` 保存白话入口，`data/ui.json` 保存界面译文。

```sh
python3 -m pip install -r requirements-build.txt
python3 build.py
python3 validate.py
python3 -m http.server 8000
```

构建生成根目录 HTML 与 `assets/index-data.js`。GitHub Pages 从 `main` 分支根目录发布，提交内容或样式更新后需一并提交重新生成的页面。`validate.py` 检查全书题号清单、必填解答字段、模拟卷分数及本地链接；它不能代替数学内容校核。
