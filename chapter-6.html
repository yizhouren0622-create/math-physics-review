格林函数：算符对点源的响应Green functions: the response to a point source

先用一句话理解Begin with the idea

格林函数先回答“只在一个点放入单位源，会发生什么”。一般分布的源再由这些点源响应叠加得到；第一步先固定方程的正负号。

A Green function is the response to a unit source at one point. Add weighted point-source responses to solve for a general source. Fix the operator’s sign convention first.

再看数学表述Open the mathematical explanation＋

把一般源分解成点源，先求算符对一个点源的响应，再积分叠加。本章采用教材约定 ΔG=δ；若改用 −ΔG=δ，所有格林函数整体变号。

Imagine building a general source from many tiny point sources. First find the response to one unit point source, then add the responses by integration. This chapter follows the textbook convention ΔG=δ; with the alternative convention −ΔG=δ, every Green function changes its overall sign.

ΔGd=δ,G1=|x−x0|2,G2=ln|r−r0|2π,G3=−14π|r−r0|
使用条件When it applies

等式在分布意义成立，源点以外均为调和函数。无界域须额外说明无穷远条件；一维基本解还可加任意仿射函数，二维需约定对数中的参考长度。

The equality holds in the sense of distributions: the point source is included, while the function is harmonic away from it. An unbounded domain also needs a condition at infinity. In one dimension any affine function may be added; in two dimensions the logarithm needs a reference length.

展开证明 / 推导Open proof / derivation＋

先固定符号 ΔG=δ。把源点附近任意小体积中的方程积分，右边总是 1；散度定理把左边变成边界外向通量，所以基本解的关键是“源点外调和，小球通量为 1”。下面给出三种维数的核心计算，点源等式按分布理解。

First fix the sign convention ΔG=δ. Integrating over any small neighborhood of the source gives 1 on the right. The divergence theorem converts the left side to outward boundary flux. A fundamental solution must therefore be harmonic away from the source and have unit small-boundary flux. The following calculations cover three dimensions of space, with the point-source equality interpreted distributionally.

三维令 R=|r−r0|，球对称源外方程是 (R2G′)′=0。积分得 G=A+B/R，于是 G′=−B/R2。乘球面积 4πR2 得通量 −4πB=1，所以 B=−1/(4π)；取三维无穷远零值时 A=0。

In three dimensions, let R=|r−r0|. The radial equation away from the source is (R2G′)′=0. Integrating gives G=A+B/R, so G′=−B/R2. Multiplying by the sphere area 4πR2 gives flux −4πB=1, hence B=−1/(4π). Choosing zero value at three-dimensional infinity sets A=0.

二维圆对称源外方程是 (RG′)′=0，积分得 G=A+BlnR。圆周外向通量为 2πRG′=2πB，故 B=1/(2π)。严格写成 ln(R/R*)/(2π)，其中参考长度 R* 只改变一个常数；二维对数基本解不能像三维那样在无穷远趋零。

In two dimensions, the radial source-free equation is (RG′)′=0, giving G=A+BlnR. The outward circular flux is 2πRG′=2πB, hence B=1/(2π). Write the logarithm as ln(R/R*)/(2π) if a dimensionless argument is needed. The reference length R* changes only a constant; unlike the three-dimensional inverse distance, this logarithmic fundamental solution cannot decay at infinity.

一维在源点两侧有 G′′=0，因此各为直线；函数连续以避免额外的 δ′。跨源点积分给 G′(x0+)−G′(x0−)=1，对称选择 G=|x−x0|/2 的两斜率为 1/2,−1/2，正好符合。任意 Ax+B 仍可加入；三种形式的符号由通量或斜率跳跃决定，不能靠记忆统一套负号。

In one dimension, G′′=0 on both sides of the source, so each side is a straight line. Continuity avoids an extra δ′. Integration across the source gives G′(x0+)−G′(x0−)=1. The symmetric choice G=|x−x0|/2 has right and left slopes 1/2,−1/2, as required. Any Ax+B may still be added. In all three cases, flux or a slope jump fixes the sign; one cannot attach the same remembered negative sign in every dimension.

做一道简单例题Try a worked example＋

为什么 1/(4πr) 不符合本章基本解的符号？

Why is 1/(4πr) the wrong sign for this chapter's fundamental solution?

解答

Solution

设候选为 g(r)=1/(4πr)。在 r>0 它确实调和，但这还没有判断它对应正点源还是负点源。

Test g(r)=1/(4πr). It is harmonic for r>0, but this does not yet tell us whether its point source is positive or negative.

径向导数 g′=−1/(4πr2)，半径 ϵ 球面上的通量为 4πϵ2g′(ϵ)=−1。因此 Δg=−δ，不符合本章 ΔG=+δ。

Its radial derivative is g′=−1/(4πr2). The flux through a sphere of radius ϵ is 4πϵ2g′(ϵ)=−1. Therefore Δg=−δ, which fails this chapter’s convention ΔG=+δ.

把它整体换号为 G=−1/(4πr)，通量就变成 +1。若题目算符本来是 −Δ，则原来的正倒数又是正确选择；第一笔应始终先写算符约定。

Changing the overall sign to G=−1/(4πr) makes the flux +1. If the operator were instead −Δ, the original positive reciprocal would be correct. Always write the operator convention first.

在实轴上求满足 u′′=3δ(x−2) 的函数，要求它关于 x=2 对称且 u(2)=0。按分布理解方程；先在源点两侧求解，再确定连接条件。

On the real line, find a function satisfying u′′=3δ(x−2), symmetric about x=2, with u(2)=0. Interpret the equation distributionally. Solve on each side of the source and then determine the matching conditions.

提示 1：先选方法Hint 1: choose a method＋

源点以外二阶导数为零，所以两侧都是直线；对称性提示使用绝对值。

Away from the source the second derivative is zero, so each piece is a straight line. Symmetry suggests an absolute value.

提示 2：写第一行Hint 2: write the first line＋

写 u=C|x−2|+B。函数应连续，否则二阶导数会多出 δ′。

Write u=C|x−2|+B. The function must be continuous, or its second derivative would also contain δ′.

提示 3：关键计算Hint 3: key calculation＋

源点两侧导数为 −C,C，因此跳跃为 2C=3；参考值给 B=0。

The slopes are −C,C, giving the jump 2C=3. The reference value gives B=0.

展开完整解答Open the full solution＋

在 x≠2 处没有源，所以 u′′=0。两侧分别是仿射函数；关于源点对称并且连续时，可以统一写成 u=C|x−2|+B。

For x≠2 there is no source, so u′′=0. Each piece is affine. Symmetry about the source and continuity let us combine them as u=C|x−2|+B.

跨过源点积分，得到 u′(2+)−u′(2−)=3。右斜率是 C，左斜率是 −C，故 2C=3，即 C=3/2。

Integrating across the source gives u′(2+)−u′(2−)=3. The right slope is C and the left slope is −C, hence 2C=3, or C=3/2.

参考条件 u(2)=0 给 B=0，因此 u=3|x−2|/2。它的导数跳跃正好产生强度为 3 的点源。

The reference condition u(2)=0 gives B=0, so u=3|x−2|/2. Its slope jump produces exactly a point source of strength 3.

方程本身可以加任意仿射齐次解；本题的对称条件去掉非零斜率项，参考条件再固定常数。不能另外要求两端都衰减，因为这个解随离源距离线性增长。

The differential equation alone allows any affine homogeneous addition. Here symmetry removes a nonzero slope addition and the reference condition fixes the constant. Decay at both ends cannot be imposed as another condition, because this solution grows linearly with distance from the source.

怎样检查，哪里容易错Check your result and common mistakes＋

两侧斜率为 −3/2,3/2，相减为 3，且函数连续，没有额外的 δ′。典型错误是照搬三维基本解的负号；本题算符为 d2/dx2，负号会产生强度为负的点源。

The slopes are −3/2,3/2, with difference 3. The function is continuous, so there is no extra δ′. A common error is to copy the negative sign of the three-dimensional fundamental solution. Here the operator is d2/dx2, so that sign would give a negative source strength.

Dirichlet 格林函数与边界积分Dirichlet Green functions and boundary integrals

先用一句话理解Begin with the idea

边界值已知时，要让格林函数在边界上为零。简单平面可用镜像相消；写完后检查源点、边界和无穷远。

For prescribed boundary values, use a Green function that vanishes on the boundary. Images work for simple planes. Check the source singularity, boundary, and infinity.

再看数学表述Open the mathematical explanation＋

格林函数既要产生单位点源，还要满足齐次边界条件。镜像源放在求解区域之外，目的在于抵消边界值，不能在区域内部额外制造奇点。

A Green function must produce one unit point source and satisfy a zero boundary condition. An image source is an imaginary helper placed outside the region being solved. Its job is to cancel the boundary value; it must not introduce another singularity inside the region.

u(r)=∫VG(r,r′)f(r′)dV′+∫∂Vφ(r′)∂n′G(r,r′)dS′
使用条件When it applies

Δr′G=δ(r′−r)，G|∂V=0，Δu=f，u|∂V=φ；n′ 是区域的外法向。外域另需足够的无穷远条件。

Δr′G=δ(r′−r), G|∂V=0, Δu=f, and u|∂V=φ. Here n′ points out of the region. An exterior domain also needs suitable conditions at infinity.

展开证明 / 推导Open proof / derivation＋

固定观察点 r，把带撇号的 r′ 当积分变量。选 Δr′G=δ(r′−r) 且 G=0 于边界：前者保证读出观察点的值，后者用来消掉未知边界导数。这两个要求各有作用，缺一不可。

Fix the observation point r and use r′ as the integration variable. Choose Δr′G=δ(r′−r) and G=0 on the boundary. The first condition extracts the observation value; the second removes an unknown boundary derivative. Both are needed.

从第二格林公式 ∫V(uΔG−GΔu)dV′=∮∂V(u∂n′G−G∂n′u)dS′ 出发。代入 Δu=f，再用点源的取值性质 ∫u(r′)δ(r′−r)dV′=u(r)，左边成为 u(r)−∫VGfdV′。

Start from Green’s second identity: ∫V(uΔG−GΔu)dV′=∮∂V(u∂n′G−G∂n′u)dS′. Insert Δu=f and the sampling property ∫u(r′)δ(r′−r)dV′=u(r). The left side becomes u(r)−∫VGfdV′.

在边界，G=0 消掉原本不知道的 ∂n′u 项，已知 u=φ 则留下 ∮φ∂n′GdS′。把体源项移到右边，得到 u=∫VGfdV′+∮φ∂n′GdS′；两项分别对应源与边界输入。

On the boundary, G=0 removes the otherwise unknown ∂n′u term, while the known value u=φ leaves ∮φ∂n′GdS′. Move the source term to the right to get u=∫VGfdV′+∮φ∂n′GdS′. These are the source and boundary contributions.

这是可跟算的核心推导。严谨处理奇点时，先挖去观察点的小球，再分部积分并取球半径趋零；小球边界给出上述 u(r)。镜像法只是构造合适 G 的办法，像点必须在域外；无界域还要检查无穷远边界项消失及积分收敛，法向始终取求解域的外法向。

This is the core derivation. To treat the singularity rigorously, remove a small ball around the observation point, integrate by parts, and shrink the ball; its boundary supplies the term u(r). The image method is only a way to construct a suitable G, and images must lie outside the domain. An unbounded domain also requires convergence and vanishing boundary terms at infinity. Normals always point outward from the region being solved.

做一道简单例题Try a worked example＋

上半空间、零边界、单位点源的格林函数如何构造？

How do we construct the Green function for a unit point source in the upper half-space with zero boundary values?

解答

Solution

真实源位于 (x0,y0,z0)，y0>0；镜像放在 (x0,−y0,z0)。对观察点 (x,y,z) 定义 R2=(x−x0)2+(y−y0)2+(z−z0)2，R*2=(x−x0)2+(y+y0)2+(z−z0)2。

Place the real source at (x0,y0,z0) with y0>0, and its image at (x0,−y0,z0). For an observation point (x,y,z), define R2=(x−x0)2+(y−y0)2+(z−z0)2 and R*2=(x−x0)2+(y+y0)2+(z−z0)2.

取 G=−1/(4πR)+1/(4πR*)。代 y=0 时两个平方距离完全相同，所以 G=0；域内只有第一项的源点，第二项在整个上半空间调和。

Choose G=−1/(4πR)+1/(4πR*). At y=0, the squared distances are identical, so G=0. Only the first term has a source inside; the second term is harmonic throughout the upper half-space.

若还需要求给定平面值的解，就对积分变量的源点高度求导，外法向取向下，得到正核 P=y/[2π((x−ξ)2+y2+(z−ζ)2)3/2]。源项为零时 u=∫R2Pφdξdζ；恒定 φ=C 时核积分为1，返回 u=C。

For prescribed plane values, differentiate with respect to the integration-source height using the downward outward normal. This gives the positive kernel P=y/[2π((x−ξ)2+y2+(z−ζ)2)3/2]. With zero interior source, u=∫R2Pφdξdζ. A constant φ=C returns u=C, since the kernel integrates to 1.

圆盘半径为 2，盘内满足 Δu=0，边界为 u(2,θ)=2+cosθ+3cos(2θ)。求盘内有限的解及圆心值。可用 Poisson 积分的模态性质：边界 cos(nθ) 延拓为 (r/2)ncos(nθ)，常数保持不变。

A disk has radius 2. Inside, Δu=0, and the boundary is u(2,θ)=2+cosθ+3cos(2θ). Find the finite interior solution and its center value. You may use the modal property of the Poisson integral: boundary data cos(nθ) extend to (r/2)ncos(nθ), while constants remain unchanged.

提示 1：先选方法Hint 1: choose a method＋

把边界拆成常数、第一角模态和第二角模态，再利用线性叠加。

Split the boundary into the constant, first angular mode, and second angular mode, then use linear superposition.

提示 2：写第一行Hint 2: write the first line＋

三个径向因子分别为 1、r/2、(r/2)2；原来的幅值要保留。

The radial factors are 1, r/2, and (r/2)2. Retain the original amplitudes.

提示 3：关键计算Hint 3: key calculation＋

合并为 u=2+(r/2)cosθ+3(r/2)2cos(2θ)。

Combine them as u=2+(r/2)cosθ+3(r/2)2cos(2θ).

展开完整解答Open the full solution＋

边界已经分成三个 Fourier 模态。常数项的盘内解仍是 2；第一角模态用 r/2 保证边界幅值为 1；第二角模态用 (r/2)2 保证边界幅值为 3。

The boundary is already split into three Fourier modes. The constant interior solution remains 2. The first angular mode uses r/2 to give boundary amplitude 1, and the second uses (r/2)2 to give boundary amplitude 3.

利用 Laplace 方程的线性性相加，得到 u=2+(r/2)cosθ+3(r/2)2cos(2θ)。各径向幂在圆心都有限，无须加入负幂。

By linearity of the Laplace equation, add them to obtain u=2+(r/2)cosθ+3(r/2)2cos(2θ). All radial powers are finite at the center; no negative powers are needed.

令 r=0，两个非常数模态均消失，所以 u(0)=2。这也等于边界平均值，因为两个余弦在一周上的积分都为零。

Setting r=0 removes both nonconstant modes, so u(0)=2. This is also the boundary average, because each cosine integrates to zero over one full turn.

怎样检查，哪里容易错Check your result and common mistakes＋

代 r=2 恢复题设边界。还可写成 u=2+x/2+3(x2−y2)/4，有 uxx+uyy=3/2−3/2=0。典型错误是所有角模态都乘同一个 r/2；第二模态必须用二次幂。

Setting r=2 recovers the boundary. Alternatively write u=2+x/2+3(x2−y2)/4, for which uxx+uyy=3/2−3/2=0. A common error is to give every angular mode the same factor r/2; the second mode needs the second power.

Neumann 相容条件、常数自由度与 Robin 边界Neumann compatibility, the arbitrary constant, and Robin boundaries

先用一句话理解Begin with the idea

只给边界上的流量，温度整体加一个常数通常不受影响。先检查总源强与总流量是否平衡；Robin边界还要额外检查是否出现特殊参数。

Flux data usually leave an additive constant undetermined. Check the balance of total source and boundary flux first. Robin conditions also require checking exceptional parameters.

再看数学表述Open the mathematical explanation＋

给定法向导数并不确定整体常数。更关键的是源的总量必须等于流出边界的总通量。有界域中不能同时要求 ΔG=δ 和处处零法向导数。

Prescribing the normal derivative does not fix the overall constant in u. Before solving, check that the total source equals the total outward boundary flux. In a bounded domain, a Green function cannot satisfy both ΔG=δ and zero normal derivative everywhere.

∫VfdV=∮∂VgdS,ΔGN=δ−1|V|,∂nGN=0
使用条件When it applies

域连通且有界，Δu=f、∂nu=g。修正型 Neumann 格林函数另用 ∫VGN=0 固定常数；也可保持 ΔG=δ 而给 G 非零的相容通量。Robin 条件应检查齐次问题是否有非零解。

The domain is connected and bounded, with Δu=f and ∂nu=g. For the modified Neumann Green function, impose ∫VGN=0 to fix its constant. Alternatively, keep ΔG=δ and give G a compatible nonzero boundary flux. For a Robin condition, check whether the homogeneous problem has a nonzero solution.

展开证明 / 推导Open proof / derivation＋

第一步先做总量检查。把 Δu=f 在域内积分，散度定理给 ∫VfdV=∮∂V∂nudS=∮∂VgdS。左边是全部源量，右边是全部外向通量；它们不相等时，不必继续求函数，因为任何解都不可能满足方程。

First check the total balance. Integrate Δu=f over the domain and apply the divergence theorem: ∫VfdV=∮∂V∂nudS=∮∂VgdS. The total source must equal total outward flux. If the totals differ, no function can satisfy the problem, so further solving is unnecessary.

再看为什么只差一个常数。若 u1,u2 有同一源和同一 Neumann 边界，令 w=u1−u2，则 Δw=0,∂nw=0。分部积分给 ∫V|∇w|2dV=∮w∂nwdS−∫VwΔwdV=0；因此 ∇w=0，连通域中 w 为常数。

Next explain the arbitrary constant. If u1,u2 have the same source and Neumann data, let w=u1−u2. Then Δw=0,∂nw=0. Integration by parts gives ∫V|∇w|2dV=∮w∂nwdS−∫VwΔwdV=0. Thus ∇w=0, so w is constant in a connected domain.

对格林函数也必须做同样的总量检查。若硬要求 ΔG=δ 且 ∂nG=0，积分会得到 1=0，因此这种有界域构造不存在。把点源改为 ΔGN=δ−1/|V| 后，总源变为 1−|V|/|V|=0，才与零法向导数相容。

The Green function must satisfy the same balance. Requiring both ΔG=δ and ∂nG=0 would give 1=0 after integration, so that bounded-domain construction is impossible. Instead use ΔGN=δ−1/|V|. Its total source is 1−|V|/|V|=0, compatible with zero normal derivative.

还需用 ∫VGNdV=0 固定格林函数自身的常数。格林公式中 ∫u(δ−1/|V|)dV=u−u¯，其中 u¯=|V|−1∫VudV，所以公式确定的是相对平均值；要确定绝对值，另给平均值或一个点的值。这里推导必要条件与常数自由度，存在性还采用相应椭圆边值问题理论。

Impose ∫VGNdV=0 to fix the Green function’s own constant. In Green’s formula, ∫u(δ−1/|V|)dV=u−u¯, where u¯=|V|−1∫VudV. The representation therefore determines the value relative to the mean. Prescribing the mean or one point value fixes the absolute value. This establishes the necessary balance and constant freedom; existence also relies on the relevant elliptic boundary-value theory.

Robin 边界要另查齐次解。例如差函数满足 ∂nw+αw=0 时，能量式变成 ∫|∇w|2=−∮αw2。若 α≥0 且在一部分边界严格为正，只能有 w=0；若系数变号或为负，可能出现共振，不能自动宣称唯一。纯 α=0 又回到 Neumann 的常数自由度。

Check homogeneous solutions separately for a Robin boundary. If the difference satisfies ∂nw+αw=0, its energy identity is ∫|∇w|2=−∮αw2. If α≥0 and is strictly positive on part of the boundary, only w=0 is possible. Sign-changing or negative coefficients can admit resonances, so uniqueness is not automatic. Pure α=0 returns to the Neumann constant freedom.

亥姆霍兹基本解与辐射条件Helmholtz fundamental solutions and radiation conditions

先用一句话理解Begin with the idea

同一频率下的波场需要区分向外传播与向内传播。先固定时间因子的约定，再用辐射条件选择正确的指数符号。

A single-frequency wave field must distinguish outgoing from incoming waves. Fix the time convention, then use the radiation condition to select the exponential sign.

再看数学表述Open the mathematical explanation＋

对空间简谐波，径向基本解是球面波除以距离。正负指数都满足同一个点源方程，区别来自辐射条件；判断出射和入射还必须说明时间因子。

For a time-harmonic wave, the radial fundamental solution is a spherical wave divided by distance. Both signs in the exponential satisfy the same point-source equation. The radiation condition selects one sign, and the time factor tells us which wave is outgoing.

(Δ+k2)G±=δ,G±(R)=−e±ikR4πR
使用条件When it applies

k>0，三维无界均匀空间。在时间因子 e−iωt 下，e+ikR/R 为出射波，满足 R(∂RG−ikG)→0；若时间因子改为 e+iωt，命名反转。

k>0 in uniform, unbounded three-dimensional space. With the time factor e−iωt, e+ikR/R is outgoing and satisfies R(∂RG−ikG)→0. If the time factor is e+iωt, the outgoing/incoming names are reversed.

展开证明 / 推导Open proof / derivation＋

设 R 是到点源的距离。在 R>0 处，径向方程为 G′′+2G′/R+k2G=0。令 v=RG，利用 (RG)′′/R=G′′+2G′/R，方程变成 v′′+k2v=0。

这个常系数方程给 v=AeikR+Be−ikR，因此 G=(AeikR+Be−ikR)/R。只在源点外算微分方程不能决定 A,B；它们控制波的方向和点源强度。

The constant-coefficient equation gives v=AeikR+Be−ikR, hence G=(AeikR+Be−ikR)/R. Checking the equation only away from the source cannot determine A,B; these coefficients control wave direction and source strength.

在 R→0 展开得 G=(A+B)/R+O(1)。外向小球通量趋于 −4π(A+B)，而 k2∫R<ϵGdV=O(ϵ2)→0，故单位点源要求 A+B=−1/(4π)。分别取 B=0 或 A=0，就得到两种 G±=−e±ikR/(4πR)；结合源外方程，以挖球分部积分可得到完整分布等式。

As R→0, expand to obtain G=(A+B)/R+O(1). The small-sphere outward flux tends to −4π(A+B), while k2∫R<ϵGdV=O(ϵ2)→0. A unit source therefore requires A+B=−1/(4π). 选择出射还需远场条件。在时间因子 e−iωt 下，正指数的相位 kR−ωt 随时间向更大的 R 传播，所以它为出射；对它求导得 ∂RG+−ikG+=eikR/(4πR2)，故 R(∂RG+−ikG+)→0。负指数则不满足这一出射条件。

Selecting an outgoing wave requires a far-field condition. With time factor e−iωt, the phase kR−ωt moves toward larger R, so the positive exponent is outgoing. Differentiation gives ∂RG+−ikG+=eikR/(4πR2), hence R(∂RG+−ikG+)→0. The negative exponent fails this outgoing condition.

两种基本解之差为 G+−G−=−isin(kR)/(2πR)，在原点极限为 −ik/(2π)，是没有点源的齐次解。于是“同一方程可有不同基本解”来自不同附加条件；若时间因子改成 e+iωt，入射、出射的称呼相反。

The difference is G+−G−=−isin(kR)/(2πR), whose origin limit is −ik/(2π); it is a homogeneous solution without a point source. Different extra conditions thus select different fundamental solutions of the same equation. Replacing the time factor by e+iωt reverses the incoming and outgoing labels.

推迟格林函数与因果响应Retarded Green functions and causal response

先用一句话理解Begin with the idea

一个点发生的变化，要过一段传播时间才影响远处。把源项的时间向前回溯“距离除以速度”，就体现了因果关系。

A disturbance takes time to reach a distant point. Evaluate the source at an earlier time, delayed by distance divided by speed, to enforce causality.

再看数学表述Open the mathematical explanation＋

波动信息以有限速度传播：观察点当前的响应，来自源点在 R/c 之前的作用。推迟解要求响应不早于源的激发。

A wave travels at a finite speed. The response observed now comes from what the source did R/c earlier. A retarded solution is causal: it cannot respond before the source acts or before the signal arrives.

Gret=δ(t−t′−R/c)4πc2R,R=|r−r′|
使用条件When it applies

此处算符为 ∂t2−c2Δ，三维无界空间，零初始响应。若算符写成 c−2∂t2−Δ，格林函数相应乘 c2；初始位移、速度不为零时要另加齐次初值解。

Here the operator is ∂t2−c2Δ in unbounded three-dimensional space, with zero initial response. For the operator c−2∂t2−Δ, multiply the Green function by c2. Nonzero initial displacement or velocity requires an additional homogeneous initial-value solution.

展开证明 / 推导Open proof / derivation＋

以下是采用 Fourier 变换与分布恒等式的核心推导。令 τ=t−t′，对空间使用 G=(2π)−3∫eik·RG^d3k 的逆变换约定。算符 ∂t2−c2Δ 变为 G^ττ+c2|k|2G^=δ(τ)，即每个空间频率都是受瞬时单位冲击的振子。

The core derivation uses Fourier transforms and distribution identities. Set τ=t−t′ and use the spatial inverse convention G=(2π)−3∫eik·RG^d3k. The operator ∂t2−c2Δ becomes G^ττ+c2|k|2G^=δ(τ): each spatial frequency is an oscillator driven by a unit impulse.

因果性要求 τ<0 时为零。跨过零时刻积分，导数必须跳跃1；为避免 δ′，函数本身连续。因此 G^=H(τ)sin(cqτ)/(cq)，其中 q=|k|。它在 τ=0+ 的值为0、导数为1，正好满足两个连接条件。

Causality requires zero response for τ<0. Integrating across zero makes the derivative jump by 1, while continuity avoids a δ′. Thus G^=H(τ)sin(cqτ)/(cq), with q=|k|. Its value at τ=0+ is 0 and its derivative is 1, satisfying both matching conditions.

逆变换时以 R 为极轴，角积分为 4πsin(qR)/(qR)。结合体积元 q2dq，对 R>0 得 G=H(τ)/(2π2cR)∫0∞sin(qR)sin(cqτ)dq；两个分母中的 q 正好抵掉体积元中的 q2。

In the inverse transform, choose the polar axis along R. The angular integral is 4πsin(qR)/(qR). Combining it with the measure q2dq, for R>0 we obtain G=H(τ)/(2π2cR)∫0∞sin(qR)sin(cqτ)dq. The two denominator factors of q cancel the q2 in the measure.

使用分布恒等式 ∫0∞sin(qR)sin(cqτ)dq=π[δ(R−cτ)−δ(R+cτ)]/2。当 R>0,τ≥0，第二项没有支撑；再用 δ(R−cτ)=δ(τ−R/c)/c，得到 Gret=δ(τ−R/c)/(4πc2R)。此正弦积分不是通常意义的收敛积分；源点及传播前沿都按分布解释。

Use the distribution identity ∫0∞sin(qR)sin(cqτ)dq=π[δ(R−cτ)−δ(R+cτ)]/2. For R>0,τ≥0, the second term has no support. With δ(R−cτ)=δ(τ−R/c)/c, this gives Gret=δ(τ−R/c)/(4πc2R). The sine integral is not an ordinarily convergent integral; both the source point and wavefront are interpreted distributionally.

Superpose the Green function with the source. The time delta selects t′=t−R/c, so the zero-initial-response solution is u(r,t)=∫f(r′,t−R/c)/(4πc2R)dV′, with the source start time respected. For the operator c−2∂t2−Δ, multiply the response by c2. Nonzero initial displacement or velocity requires an additional homogeneous initial-value solution.

    同时 ω2∫r<εG±dV=O(ε2)→0。

  3. 因而该算符在源点产生单位点源，在其余位置为零。更严格地对光滑紧支试验函数 ψ，在挖去小球的区域分部积分，内边界极限仅留下 ψ(0)，于是 ⟨(Δ+ω2)G±,ψ⟩=ψ(0)。二者均满足所求分布方程。

  4. 两解之差 G+−G−=−isin(ωr)/(2πr) 在原点有有限极限，满足齐次方程。方程本身不能选择正负号，需要辐射条件。时间因子 e−iωt 时 + 为出射；教材若采用 e+iωt，出入射称呼反向。

  1. For r>0, set v±=rG±=−e±iωr/(4π). Direct differentiation gives v±′′=−ω2v±, so ΔG±+ω2G±=0.

  2. Near r=0, expand: G±=−1/(4πr)∓iω/(4π)+O(r). Both have the same singular leading term. Thus ∂rG±=1/(4πr2)+O(1), and on a sphere of radius ε,

    ∮r=ε∂rG±dS=1+O(ε2)→1.
    Also ω2∫r<εG±dV=O(ε2)→0.

  3. The operator therefore produces a unit point source at the origin and zero elsewhere. More rigorously, take a smooth compactly supported test function ψ and integrate by parts in the region with a small sphere removed. The inner-boundary limit leaves only ψ(0), giving ⟨(Δ+ω2)G±,ψ⟩=ψ(0). Both functions satisfy the required distributional equation.

  4. Their difference G+−G−=−isin(ωr)/(2πr) has a finite limit at the origin and satisfies the homogeneous equation. The equation alone cannot select the sign; a radiation condition is needed. With the time factor e−iωt, + is outgoing. If the textbook uses e+iωt, the outgoing/incoming names are reversed.

最终答案

Final answer

两种函数均满足 (Δ+ω2)G=δ；源点外为齐次解，小球通量均趋于 1。

Both functions satisfy (Δ+ω2)G=δ: each solves the homogeneous equation away from the source and has small-sphere flux tending to 1.
