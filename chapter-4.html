朗斯基行列式与阿贝尔公式

二阶齐次线性方程的解空间在一个正则区间内是二维的。两个解能否作为一组基底，由 W=y1y2′−y1′y2 判断。一个点的 W≠0 已能保证整个正则区间内线性独立。

W(x)=W(x0)exp[−∫x0xP(t)dt]
使用条件

标准式 y′′+P(x)y′+Q(x)y=0，P,Q 在连通区间连续；两个函数必须是该方程的解。

展开证明 / 推导＋

由定义求导：W′=y1y2′′−y1′′y2。代入 yi′′=−Pyi′−Qyi，Q 项相消，得到 W′=−PW。分离变量，或用一阶方程积分因子，得到阿贝尔公式。若 W(x0)=0，初值向量相关，再用线性初值问题唯一性推出两个解线性相关。

做一道简单例题＋

判断 ex,e−x 是否可组成 y′′−y=0 的基本解组。

解答

W=ex(−e−x)−exe−x=−2≠0，所以是基本解组；通解为 C1ex+C2e−x。

记忆线索

先除最高阶系数，再读出一阶导系数；W 的指数中带负号。

常点幂级数与正则奇点 Frobenius 法

常点用 y=∑an(x−x0)n；正则奇点用 y=(x−x0)r∑an(x−x0)n。最低次幂给指标方程，其余各次幂给递推。特殊函数的多项式解来自递推系数在某一级变成零。

y=(x−x0)r∑n=0∞an(x−x0)n,a0≠0
使用条件

先写标准式 y′′+Py′+Qy=0。若 (x−x0)P、(x−x0)2Q 解析，则为正则奇点。整数差或重指标根需检查对数解。

展开证明 / 推导＋

若 (x−x0)P=p0+p1(x−x0)+⋯，(x−x0)2Q=q0+q1(x−x0)+⋯，代入后最低次幂系数是 a0[r(r−1)+p0r+q0]，故指标方程为 r(r−1)+p0r+q0=0。之后逐次比较系数，得到 an 递推；不可只求指标根就停止。

做一道简单例题＋

求 x2y′′+xy′−ν2y=0 的指标根及解。

解答

代入 y=xr 得 r(r−1)+r−ν2=r2−ν2=0。ν≠0 时 y=C1xν+C2x−ν（取 x>0）；ν=0 时第二解为 lnx。

记忆线索

最低幂找指数，同幂比较找递推，分母为零查对数。

本节无书后习题
知识点 理解后再记忆

常数变易法

非齐次线性方程的通解等于齐次通解加一个特解。让齐次解前的常数变为函数，并增加一个辅助条件，可把求特解降为两个积分。

yp=−y1∫y2fWdx+y2∫y1fWdx
使用条件

针对标准式 y′′+Py′+Qy=f，y1,y2 为齐次基本解，W=y1y2′−y1′y2≠0。非标准式需先除最高阶系数。

展开证明 / 推导＋

令 yp=u1y1+u2y2，规定 u1′y1+u2′y2=0。代入方程后剩 u1′y1′+u2′y2′=f。解二元方程得 u1′=−y2f/W、u2′=y1f/W，分别积分即得公式。积分常数已经包含在齐次通解中。

做一道简单例题＋

求 y′′+y=1 的通解。

解答

取 y1=cosx,y2=sinx,W=1。yp=−cosx∫sinxdx+sinx∫cosxdx=cos2x+sin2x=1，故 y=C1cosx+C2sinx+1。

记忆线索

先齐次，后特解；变易积分前检查标准式。

教材习题 4.1

二阶齐次常微分方程解的线性关系

3 道主编号题
习题 4.1 · 1教材 p.167 / PDF p.176

归一化单项式的线性独立性

利用朗斯基行列式证明函数组 {xn/n!, n=0,1,…,N} 线性独立。

提示：从哪里入手＋

第 k 阶导数作用于次数小于 k 的多项式会变成零。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

按函数次数从低到高排列，求导后形成上三角矩阵。

逐步解答

设 fj=xj/j!（j=0,…,N）。第 i 行取 i 阶导数，则

fj(i)={xj−i/(j−i)!,j≥i,0,j<i.
该矩阵是上三角矩阵，所有对角元 fi(i)=1，故 W(f0,…,fN)=1。 若 ∑cjfj≡0，在任意一点连续求导 0,…,N 次得到一个系数矩阵行列式为 1 的齐次方程组，只能有 c0=⋯=cN=0。所以线性独立。

最终答案

W=1，该函数组线性独立。

这一类题的答题套路与易错点＋

可复用步骤

单项式组按次数升序排列，导数矩阵上三角，直接乘对角元。

易错点

本题有 N+1 个函数，W 应是 (N+1)×(N+1)；不能少取常数项。

题目链接
习题 4.1 · 2教材 p.167 / PDF p.176条件 / 勘误

W 恒为零时何时能推出相关

如果两个函数 y1(x) 和 y2(x) 的朗斯基行列式恒为零，证明它们满足 y1(x)=cy2(x)，c 为常数，即线性相关。

读题注意

对任意可微函数，W≡0 未必推出整个区间内线性相关；需要同一正规齐次方程解等额外条件。解析给出反例与正确证明。

提示：从哪里入手＋

计算 (y1/y2)′；同时想一想分母为零处能否跨越。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

先检查命题适用条件；在 y₂ 非零的连通区间可通过商的导数证明，但任意光滑函数在跨过公共零点时结论不一定成立。

逐步解答

在 y2≠0 的一个连通区间上，

(y1y2)′=y1′y2−y1y2′y22=−Wy22=0,
所以 y1=cy2。若两函数是同一个正则二阶线性齐次方程的解，可任选一个 y2(x0)≠0 的点令 c=y1(x0)/y2(x0)；W(x0)=0 同时给 y1′(x0)=cy2′(x0)。差函数具有零初值，由唯一性在整个正则区间等于零。

题干条件说明：对任意光滑函数，原命题并不成立。例如 (−1,1) 上令 y1=e−1/x2（x>0）、其余为零；y2=e−1/x2（x<0）、其余为零。两函数都是 C∞，支撑互不相交，故 W≡0，却不成比例。另若 y2≡0 而 y1≢0，两函数线性相关，但不能写成题干指定的 y1=cy2。

最终答案

在 y2≠0 的连通区间，或补充“同一正则齐次 ODE 的解且 y2≢0”后，y1=cy2。一般函数版本需修正。

这一类题的答题套路与易错点＋

可复用步骤

W=0 先用商导数作局部证明；要全区间结论，补唯一性或解析性依据。

易错点

W 非零足以判独立；W 恒零对任意光滑函数不总能判相关。

题目链接
习题 4.1 · 3教材 p.167 / PDF p.176条件 / 勘误

阿贝尔公式及教材公式的条件

证明二阶线性齐次常微分方程 p(x)y′′+q(x)y′+r(x)y=0 的朗斯基行列式为 L=C/p(x)，其中 C 为常数。

读题注意

原命题缺少 q=p′ 条件。一般 Abel 公式为 W=Cexp(−∫q/pdx)；只有自伴形式才有 W=C/p。

提示：从哪里入手＋

W′=y1y2′′−y1′′y2，再用原方程消去二阶导数。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

直接求 W 的导数，确定教材给定结论是否需要 q=p′。

逐步解答

在 p≠0 的正则区间上，yi′′=−(q/p)yi′−(r/p)yi。因此

W′=−qp(y1y2′−y1′y2)=−qpW,
从而
W=Cexp(−∫q(x)p(x)dx).
只有当 q=p′（方程可写成 (py′)′+ry=0）时，W=C/p 才成立。也可直接把自伴形式代入：(pW)′=p′W+pW′=(p′−q)W=0。

反例：y′′+y′=0 中 p=1,q=1，取 1,e−x 得 W=−e−x，不是常数 C/p=C。故按题面原式无法无条件证明，必须补充 q=p′。

最终答案

一般式为 W=Ce−∫q/pdx；若 q=p′，则 W=C/p。

这一类题的答题套路与易错点＋

可复用步骤

先标准化，再用 W′=−(一阶导系数)W；遇 C/p 先检查自伴形式。

易错点

最高阶系数 p 与标准式的一阶导系数 q/p 不能混淆。

Hermite 方程与终止级数

在 x0=0 邻域用级数求解 y′′−2xy′+(λ−1)y=0。确定何时解可退化为多项式。把最高次幂归一化为 (2x)n 得 Hn(x)，写出前三阶 Hermite 多项式。

提示：从哪里入手＋

比较 xᵏ 系数，得到 aₖ₊₂ 与 aₖ 的关系。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

常点展开，偶数项和奇数项形成互不相连的两条递推链；链在次数 n 处终止。

逐步解答

设 y=∑k≥0akxk，代入并统一幂次得

∑k≥0[(k+2)(k+1)ak+2+(λ−1−2k)ak]xk=0.
故
ak+2=2k+1−λ(k+2)(k+1)ak.
于是两支独立解分别由任意 a0、a1 决定：
y=a0[1+1−λ2!x2+(1−λ)(5−λ)4!x4+⋯]+a1[x+3−λ3!x3+(3−λ)(7−λ)5!x5+⋯].
两支级数均对所有有限 x 收敛。若有 n 次非零多项式，最高次系数要求 λ−1−2n=0，即 λ=2n+1，n=0,1,…。再取与 n 同奇偶的递推链，另一链系数置零，便得到终止解。 最高次系数固定为 2n 后：H0=1，H1=2x，H2=4x2−2，H3=8x3−12x。若“前三阶”从一阶数起，答案是 H1,H2,H3；同时列出零阶避免歧义。

最终答案

λ=2n+1 时存在 n 次多项式解；H0=1,H1=2x,H2=4x2−2,H3=8x3−12x。

这一类题的答题套路与易错点＋

可复用步骤

求递推→令最高次那一级分子为零→保留同奇偶链→按最高次系数归一化。

易错点

参数满足终止条件仅保证一支为多项式，通解的另一支通常仍是无穷级数。

习题 4.2 · 2教材 p.180 / PDF p.189

Chebyshev 方程的偶奇级数

在 x0=0 邻域用级数求解 (1−x2)y′′−xy′+n2y=0。

提示：从哪里入手＋

xᵏ 项中 −x²y″−xy′ 合成 −k²aₖ。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

这是常点，递推跨两个次数；也可用 x=sin t 验证答案。

逐步解答

设 y=∑akxk，系数比较得

ak+2=k2−n2(k+2)(k+1)ak.
所以
y=a0∑j=0∞∏s=0j−1[(2s)2−n2](2j)!x2j+a1∑j=0∞∏s=0j−1[(2s+1)2−n2](2j+1)!x2j+1,
空乘积取 1，通常收敛半径为 1。整数 n≥0 时，与 n 同奇偶的一支在 n 次终止，归一化为 Tn(x)，满足 Tn(cost)=cosnt。 为核对，令 x=sint，链式法则给 (1−x2)y′′−xy′=ytt，方程化为 ytt+n2y=0。当 n≠0，通解可写为 C1cos(narcsinx)+C2sin(narcsinx)；n=0 时为 C1+C2arcsinx。

最终答案

递推 ak+2=(k2−n2)ak/[(k+2)(k+1)]，两条偶奇级数组成局部通解。

这一类题的答题套路与易错点＋

可复用步骤

含 1−x² 的方程先做常点级数；用 x=sin t 或 cos t 检查特殊函数。

易错点

n=0 时不能把两支都写成 cos、sin 后认为第二支为零，应取极限得到 arcsin x。

习题 4.2 · 3教材 p.180 / PDF p.189

超几何方程的 Frobenius 级数

在 x0=0 邻域用级数求解 x(x−1)y′′+[(1+a+b)x−c]y′+aby=0。

提示：从哪里入手＋

用 y=xʳΣaₖxᵏ，最低幂系数是 r(r+c−1)。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

0 为正则奇点。先乘 −1 化成标准 Gauss 方程，指标为 0 与 1−c。

逐步解答

改写为 x(1−x)y′′+[c−(a+b+1)x]y′−aby=0。代入 y=xr∑k≥0dkxk，最低次项给

r(r+c−1)=0,
下一组系数给
dk+1=(k+r+a)(k+r+b)(k+r+1)(k+r+c)dk.
定义 (a)k=a(a+1)⋯(a+k−1)，则对 c∉Z，
y=C12F1(a,b;c;x)+C2x1−c2F1(a−c+1,b−c+1;2−c;x),
其中 2F1(a,b;c;x)=∑k≥0(a)k(b)kxk/[(c)kk!]，|x|<1，并选择 x1−c 的一个分支。 当 c 为整数，两指标重根或相差整数，以上两项可能不定义或相关，不能盲套。先用递推找一支非零解 y1，再由标准式的一阶导系数 P=c/x+(c−a−b−1)/(1−x) 得
y2=y1∫x−c(1−x)c−a−b−1y12dx.
该式在 y1≠0 的局部区间给出第二解，展开积分即可得到必要的对数项，也涵盖退化参数。

最终答案

一般参数通解为两支 Gauss 超几何级数；整数 c 的共振情形由递推加降阶积分求第二解。

这一类题的答题套路与易错点＋

可复用步骤

标准化符号→指标方程→递推→识别 Pochhammer 系数→检查参数分母及整数差。

易错点

原方程是 x(x−1)，先乘负号；c 是非正整数时第一支常用级数分母可能为零。

题目链接
习题 4.2 · 4教材 p.180 / PDF p.189

合流超几何方程

在 x=0 邻域求解 xy′′+(c−x)y′−ay=0。

提示：从哪里入手＋

指标仍为 0 与 1−c；递推 aₖ₊₁=(k+r+a)aₖ/[(k+r+1)(k+r+c)]。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

同样用 Frobenius，但递推分子只有一个线性因子。

逐步解答

取 y=xr∑dkxk，代入得指标方程 r(r+c−1)=0，且

dk+1=k+r+a(k+r+1)(k+r+c)dk.
定义 M(a,c,x)=1F1(a;c;x)=∑k≥0(a)kxk/[(c)kk!]。当 c∉Z，
y=C1M(a,c,x)+C2x1−cM(a−c+1,2−c,x).
这些级数对所有有限 x 收敛（分母参数不触发极点时），x1−c 需选定分支。 整数 c 时应检查重根和递推分母：在得到一支 y1 后，标准式 P=c/x−1 给出
y2=y1∫exx−cy1−2dx.
积分的 Laurent 展开中 x−1 项产生 lnx，此公式也适用于特殊终止参数。若 a=−n，n≥0 且分母允许，一支在 n 次终止为多项式。

最终答案

y=C11F1(a;c;x)+C2x1−c1F1(a−c+1;2−c;x)（非整数 c）；共振参数用降阶积分。

这一类题的答题套路与易错点＋

可复用步骤

合流型递推“一个升阶因子除两个因子”；整数 c 不能略过共振检查。

易错点

a 的负整数对应终止，不是正整数；标准式 P=c/x−1 的积分因子给 eˣ。

题目链接
习题 4.2 · 5教材 p.180 / PDF p.189条件 / 勘误

Legendre 方程在 x=1 的展开

在 x=1 邻域求解 (1−x2)y′′−2xy′+l(l+1)y=0。

读题注意

公开参考图片未给完整的第二支解，且递推式需包含上一项系数。解析补出重根 Frobenius 的对数支及降阶积分。

提示：从哪里入手＋

令 t=x−1，得到 t(t+2)yₜₜ+2(t+1)yₜ−l(l+1)y=0。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

把奇点移到零，指标重根 0；第一解为常规级数，第二解一般含对数。

逐步解答

令 t=x−1，乘 −1 后方程为 t(t+2)ytt+2(t+1)yt−l(l+1)y=0。设 y=tr∑dktk，指标方程 2r2=0，故 r=0 为重根。对第一支取 d0=1，比较 tᵏ 得

dk+1=l(l+1)−k(k+1)2(k+1)2dk,
所以
y1=∑k=0∞(−l)k(l+1)k(k!)2(1−x2)k=2F1(−l,l+1;1;1−x2).
其解析半径至少到另一奇点 x=−1，即 |x−1|<2；非负整数 l 时终止，成为 Pl(x)。标准式一阶导系数 P=−2x/(1−x2)，故 e−∫Pdx=1/(1−x2)（常数倍不影响）。于是
y2=y1∫dx(1−x2)y1(x)2.
因为 y1(1)=1，被积函数在 x=1 有首项 −1/[2(x−1)]，所以 y2=−12y1ln|x−1|+解析项。局部通解为 C1y1+C2y2。例如 l=0 得 y1=1、y2=12ln|(1+x)/(1−x)|。

最终答案

解析支为 Pl(x)=2F1(−l,l+1;1;(1−x)/2)；另一支由上式降阶积分给出，一般含对数。

这一类题的答题套路与易错点＋

可复用步骤

移奇点→重指标→求一支→用 W 或降阶积分构造对数支。

易错点

在 x=1 不能直接使用以零为中心的普通幂级数来声称有两支解析解。

Laguerre 方程与教材的归一化

在 x=0 邻域求解 xy′′+(1−x)y′+λy=0。确定多项式解的参数；最高次幂归一化为 (−x)n 得 Ln(x)，写出前三阶。

读题注意

题设最高次项为 (−x)n，与常用 Laguerre 多项式相差 n!。这是归一化约定差异，不能混用。

提示：从哪里入手＋

递推 aₖ₊₁=(k−λ)aₖ/(k+1)²；注意教材最高次系数与常用 Lₙ 定义差 n!。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

这是合流超几何方程 a=−λ,c=1；重指标 0，解析支可终止。

逐步解答

设 y=xr∑akxk，最低项为 r2a0xr−1，指标重根 r=0。解析支递推为

ak+1=k−λ(k+1)2ak,y1=a0∑k=0∞(−λ)k(k!)2xk.
第二支可由降阶得到 y2=y1∫exxy12dx；在 a0≠0 下积分含对数项。若 λ=n=0,1,…，n 次递推分子为零，解析支终止；其最高次系数为 a0(−1)n/n!，题设要求最高次为 (−x)n，故取 a0=n!。 因此教材归一化下
Ln(x)=n!∑k=0n(−1)k(nk)xkk!,
并有 L0=1，L1=1−x，L2=x2−4x+2，L3=−x3+9x2−18x+6。常见数学表格把上述多项式再除以 n!；本题按教材最高次系数约定。

最终答案

λ=n∈N0；教材约定 L1=1−x,L2=x2−4x+2,L3=−x3+9x2−18x+6（另 L0=1）。

这一类题的答题套路与易错点＋

可复用步骤

递推分子归零定本征参数，最后通过最高次系数确定整体倍数。

易错点

不要直接抄常见归一化 L2=1−2x+x2/2 而忽略题设最高次系数。
