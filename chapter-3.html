波动问题：方程与边界一起看

波动方程来自“质量×加速度＝受力”。弦横振动波速为 c=T/ρ，杆纵振动波速为 c=Y/ρ。固定端给位移条件，自由端给应力或斜率条件。

utt=c2uxx,u=∑n(Ancosωnt+Bnsinωnt)Xn(x)
使用条件

线性小振幅、均匀材料；每个边界类型要选择对应的本征函数。

展开证明 / 推导＋

令 u=XT，分离为 X″+λX=0、T″+c2λT=0。固定两端使 Xn=sin(nπx/l)，ωn=cnπ/l。用初始位移投影给 An，初速度投影除以 ωn 给 Bn。

做一道简单例题＋

两端固定弦的初始位移为 sin(πx/l)，初速度零，求振动。

解答

只有第一模态：u(x,t)=sin(πx/l)cos(cπt/l)。代回 utt=c2uxx，端点及两初值均成立。

记忆线索

位移决定余弦时间项，速度决定正弦时间项；边界先于系数。

达朗贝尔公式与特征线

无限弦的位移由两个反向传播的波叠加。初速度不是直接乘 t，而是在影响区间上积分。固定端半轴问题可以先奇延拓。

u(x,t)=φ(x−ct)+φ(x+ct)2+12c∫x−ctx+ctv(s)ds
使用条件

utt=c2uxx，全轴、无外力；初值为位移 φ 和速度 v。经典解要求足够光滑。半轴固定端用奇延拓，绝热/自由端用偶延拓。

展开证明 / 推导＋

特征变量 ξ=x−ct、η=x+ct 令方程化为 uξη=0，故 u=F(ξ)+H(η)。t=0 时 F+H=φ、c(H′−F′)=v，积分解出两函数并相加，得到所列公式。对 t 求导并令 t=0 可直接核验 v。

做一道简单例题＋

全轴初位移为 0、初速度为常数 V，位移如何变化？

解答

u=(2c)−1∫x−ctx+ctVds=Vt。空间上均匀运动，所以 uxx=utt=0，初速度正确。

记忆线索

位移取两端平均；速度取中间面积除 2c。

非齐次方程的模态方程与共振

空间边界齐次后，把外力和初值投影到相同本征函数上。每个模态都是一个受迫振子，共振时不能使用零分母的非共振公式。

qn′′+ωn2qn=Fn(t),qn=Ancosωnt+Bnsinωnt+1ωn∫0tFn(s)sin[ωn(t−s)]ds
使用条件

采用正交空间本征系，ωn>0；Bn=qn′(0)/ωn。零模态须单独解 q0′′=F0。阻尼项存在时要相应修改时间方程。

展开证明 / 推导＋

对空间本征展开代入方程并利用正交性，得到各 qₙ 方程。积分核 sinωn(t−s)/ωn 在 t=s 时为零、t 导数为 1，所以二次求导后产生 Fₙ(t)，且卷积项的两条初值均为零。

做一道简单例题＋

零初值，q′′+ω2q=Fcosωt 的共振响应是什么？

解答

代入卷积或待定系数法得 q=Ftsinωt/(2ω)。包络随 t 增长。直接求两次导数可核验强迫与零初值。

记忆线索

空间先正交投影，时间再解振子；遇零分母先检查共振。

输运问题：方程与边界一起看

热量守恒与傅里叶导热定律给热方程。无源热方程的各非零空间模态随时间指数衰减；保温边界保留零模态，固定零温边界没有零模态。

ut=κΔu+s,κ=kρc
使用条件

均匀介质，k 为导热系数、ρc 为单位体积热容；外源 s 已除以热容。

展开证明 / 推导＋

一维小段 dx 的内能增加率为 ρcSutdx；两端净输入热率为 kS[ux(x+dx)−ux(x)]。除以 Sdx 并取极限得 ρcut=kuxx+q。分离变量使时间因子满足 T′+κλT=0，所以 T=e−κλt。

做一道简单例题＋

两端零温杆初温 sin(2πx/l)，求温度。

解答

u=e−4κπ2t/l2sin(2πx/l)。空间二阶导数带来 −(2π/l)2，与时间衰减率相同。

记忆线索

热方程时间一阶，初值只要一个；频率越高衰减越快。

知识点 理解后再记忆

热核、镜像延拓与扩散尺度

无限域热核是随时间变宽的 Gaussian。半轴零温用反号镜像，半轴绝热用同号镜像。扩散影响尺度随 t 增长。

K(x,t)=e−x2/(4κt)4πκt,u(x,t)=∫RK(x−ξ,t)φ(ξ)dξ
使用条件

ut=κuxx、κ>0、t>0、无源全轴。初值按连续点极限或适当 Lᵖ 意义恢复。半轴边界必须先区分 Dirichlet 和 Neumann。

展开证明 / 推导＋

Fourier 变换给 u^t=−κk2u^，故 u^=e−κk2tφ^。Gaussian 逆变换给 K，且 ∫Kdx=1。奇延拓在半轴化为 K(x−ξ)−K(x+ξ)，使 x=0 的值抵消；偶延拓化为加号，使 x=0 的导数抵消。

做一道简单例题＋

初温为单位点脉冲，其总热量随时间改变吗？

解答

温度为 K，总热量 ∫Kdx=1 保持不变；峰值按 t−1/2 降低，宽度按 κt 增大。

记忆线索

热核总量为 1；零值边界相减，零导数边界相加。

知识点 理解后再记忆

非齐次边界先齐次化

直接分离变量要求齐次边界。先找一个满足边界的简单函数 h，再令 u=v+h。若边界随时间变，v 的方程通常出现新的源项。

u=v+h,vt−κvxx=f−(ht−κhxx)
使用条件

例如 u(0,t)=A(t)、u(L,t)=B(t) 可选 h=A+(B−A)x/L。v 的边界为零，但初值必须同时减 h(x,0)。

展开证明 / 推导＋

把 u=v+h 逐项代入原方程，移项即可。由于 h 满足原边界，v 满足齐次边界。常值边界的线性 h 有 ht=hxx=0，不新增源；时变边界保留 −ht，否则代回原方程会有残差。

做一道简单例题＋

两端保持 0 和 T，初温为 0 的细杆，稳态是什么？

解答

h=Tx/L。令 v=u−h，v 两端零值、初值 −Tx/L，可作正弦展开并逐模态衰减。t→∞ 时 v→0，所以 u→Tx/L。

记忆线索

边界先减掉；初值也减掉；方程检查是否新增源。

稳定场问题：方程与边界一起看

稳态意味着时间不变，无源场满足拉普拉斯方程。矩形区域分离后，一个方向是三角函数，另一个方向是双曲函数；非齐次边界通过投影确定系数。

Δu=0,X″+λX=0,Y″−λY=0
使用条件

无源矩形区域；用齐次边界所在方向决定正交基，再满足非齐次边界。

展开证明 / 推导＋

将 u=XY 代入 uxx+uyy=0，得到 X″/X=−Y″/Y=−λ。如果 x=0,a 为零值，则 λ=(nπ/a)2、X=sin(nπx/a)。若 y=0 也为零值，Y 取 sinh(nπy/a)。

做一道简单例题＋

矩形上仅顶边给 u(x,b)=sin(πx/a)，其余三边为零。

解答

u=sin(πx/a)sinh(πy/a)/sinh(πb/a)；代入拉普拉斯方程，三零边和顶边同时满足。

记忆线索

先用齐次两边选正交基，再用双曲函数跨到非零边。

知识点 理解后再记忆

Laplace 方程的唯一性与最大值原理

边界值不仅用来定系数，也决定解是否唯一。判断两种方法的结果是否相同，可以研究两解之差。

Δw=0,w|∂V=0⟹w≡0
使用条件

有界连通域、足够正则的调和函数及 Dirichlet 边界。外域必须给无穷远条件。纯 Neumann 问题只确定到常数，且要有相容条件。

展开证明 / 推导＋

两解之差 w 满足齐次方程和零边界。Green 第一公式给 ∫V|∇w|2dV=∮w∂nw−∫wΔw=0，故 w 为常数，零边界再定为零。最大值原理也给上下界都为零。

做一道简单例题＋

球面温度恒为 5，球内无热源，温度是否可能在中心更高？

解答

常函数 5 已满足方程和边界，由唯一性只能为 5。最大值原理也排除内部超过边界最大值的稳态。

记忆线索

两解相减；能量为零；边界定常数。

施图姆–刘维尔本征值问题：方程与边界一起看

不同边界下看似不同的级数，统一来自自伴本征值问题。权函数决定投影内积。实本征值依赖自伴边界；本征值非负还需要能量二次型非负，不能只看微分方程系数。

(py′)′−qy+λwy=0,⟨f,g⟩w=∫abwfg―dx
使用条件

正则情形 p>0,w>0、q 实，配实分离自伴边界；奇异端点需额外有限性/可积性条件。

展开证明 / 推导＋

用 ym 方程乘 yn―，减去共轭的 yn 方程乘 ym，积分得 (λm−λn―)∫wymyn―=−[p(ym′yn―−ymyn′―)]ab。自伴边界使右端为零。取 m=n 得本征值实；取不同本征值便得带权正交。

做一道简单例题＋

把 xy″+(1−x)y′+ay=0 写成自伴形式。

解答

乘 e−x 后得 (xe−xy′)′+ae−xy=0，故 p=xe−x、q=0、w=e−x、λ=a。

记忆线索

先配导数项成 (py′)′；投影必须乘权函数。

四分之一点拉弦后释放

长 l、线密度 ρ、张力 T 的均匀弦，两端 x=0,l 固定。在 x=l/4 用微小横向力 F（F≪T）拉至静止后放手。(1)建立完整定解问题；(2)用分离变量法求振动。

提示：从哪里入手＋

拉点位移 h=3Fl/(16T)；也可用 −Tφ″=Fδ(x−l/4) 快速求系数。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

先由静力平衡得到三角形初位移，再展开到两端固定的正弦模态。

逐步解答

  1. 小段弦的横向力差为 Tuxxdx，质量为 ρdx，故 utt=c2uxx，c2=T/ρ。
  2. 静态弦在拉点两侧是直线。令 a=l/4、拉点高度 h，力平衡 T[h/a+h/(l−a)]=F，得 h=3Fl/(16T)。初位移为 φ(x)=3Fx/(4T)（0≤x≤l/4）、F(l−x)/(4T)（l/4≤x≤l）；初速度零。
  3. 完整条件为 u(0,t)=u(l,t)=0，u(x,0)=φ(x)，ut(x,0)=0。
  4. 取 Xn=sinknx，kn=nπ/l。由静态折点方程或分段积分得
    An=2l∫0lφ(x)sinknxdx=2FlTn2π2sinnπ4.
    因此
    u(x,t)=2FlTπ2∑n=1∞sin(nπ/4)n2sinnπxlcoscnπtl.
    张力和线密度单位分别为 N、kg/m，c 的单位确为 m/s。

最终答案

utt=(T/ρ)uxx，两端零位移、上述三角形初位移、初速度零；u=2FlTπ2∑n≥1sin(nπ/4)sin(nπx/l)cos(cnπt/l)/n2。

这一类题的答题套路与易错点＋

可复用步骤

静态拉弦 → 斜率差平衡求三角初形 → 正弦投影 → 零初速只留时间余弦。

易错点

F 是拉弦前的力；放手后方程右端为零，不应继续加入持续外力。

一端固定杆压缩后释放

均匀细杆长 l，截面积 S，质量密度 ρ，杨氏模量 Y。x=0 固定，从 x=l 压至长度 l(1−2e)，静止后放手。(1)建立纵振动定解问题；(2)分离变量求解。

提示：从哪里入手＋

初始均匀压缩给 u(x,0)=-2ex；固定—自由基为半整数正弦。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

位移相对未变形杆定义；固定端位移零，释放端应力零。

逐步解答

  1. 轴力 N=YSux，力平衡 ρSutt=(YSux)x，故 utt=c2uxx，c=Y/ρ。
  2. 放手后条件为 u(0,t)=0,ux(l,t)=0；均匀应变 −2e 给 u(x,0)=-2ex,ut(x,0)=0。
  3. 本征函数 sinknx，kn=(n+1/2)π/l，n=0,1,…。范数 l/2，投影
    An=−4el∫0lxsinknxdx=−4e(−1)nlkn2.
  4. 得
    u(x,t)=−4el∑n=0∞(−1)nkn2sinknxcos(cknt).
    初始应变在自由端并非零，反映“撤去手力”的瞬间不相容；解按能量/内部极限理解，释放后应力条件对 t>0 成立。

最终答案

utt=(Y/ρ)uxx；u(0,t)=0,ux(l,t)=0；初位移 -2ex、初速度零；上述半整数正弦级数。

这一类题的答题套路与易错点＋

可复用步骤

杆纵振动 → 杨氏应力 → 固定端/自由端区分 → 半整数频率 → 初始应变投影。

易错点

释放后的右端是零应力，不是零位移；截面积在波速中约掉。

两端自由杆压缩释放

均匀细杆长 l，截面积 S，密度 ρ，杨氏模量 Y。从两端施压使长度变为 l(1−2e)，静止后同时放手。(1)建立定解问题；(2)用分离变量法求解。

提示：从哪里入手＋

取 u(x,0)=e(l−2x)，余弦投影只有奇数模态。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

两端释放后均为零应力；以杆中心不动的对称压缩选择初位移，常数模态代表刚体平移。

逐步解答

均匀杆满足 utt=c2uxx，c=Y/ρ，边界为 ux(0,t)=ux(l,t)=0。对称压缩、中心不动时，u(x,0)=e(l−2x)、ut(x,0)=0。长度差确为 u(l,0)−u(0,0)=−2el。 Neumann基含常数和 cos(nπx/l)。初位移平均为零，常数模态不激发。对 n≥1，

An=2l∫0le(l−2x)cosnπxldx=4el[1−(−1)n]n2π2.
于是
u=8elπ2∑m=0∞cos[(2m+1)πx/l]cos[c(2m+1)πt/l](2m+1)2.
若题给压缩过程不保证中心位置，只给最终长度，则还允许在初位移和解上加任意常数 C；这仅改变刚体平移，变形与振动不变。初始端点应变与释放条件的瞬时不相容按能量解处理。

最终答案

两端 ux=0，初位移 e(l−2x)（中心固定约定），初速度零；u=8elπ2∑m≥0cos[(2m+1)πx/l]cos[c(2m+1)πt/l]/(2m+1)2，可加任意常数平移。

这一类题的答题套路与易错点＋

可复用步骤

自由—自由杆 → 余弦含零模态 → 先固定中心/平均值 → 投影得对称模态。

易错点

只给压缩长度不能决定整体平移；不要遗漏零频刚体模态。

阻尼弦方程

均匀弦在阻尼介质中横振动，单位长度所受阻力为 f=−Rut。弦线密度 ρ，张力 T。推导振动方程。

提示：从哪里入手＋

单位长度惯性为 ρutt。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

在小段受力平衡中，把分布阻力和张力差同时计入。

逐步解答

长 dx 的小段，张力竖直分量差为 T[ux(x+dx)−ux(x)]≈Tuxxdx。阻力为 −Rutdx，牛顿定律给 ρdxutt=Tuxxdx−Rutdx。因此

ρutt+Rut−Tuxx=0,
或 utt+2γut=c2uxx，其中 2γ=R/ρ、c2=T/ρ。对固定端或零通量边界，能量导数为 dE/dt=−R∫ut2dx≤0，检验了阻尼号应为正。

最终答案

utt+(R/ρ)ut=(T/ρ)uxx。

这一类题的答题套路与易错点＋

可复用步骤

受力微元 → 单位长度统一 → 阻力反向 → 能量衰减核验符号。

易错点

若写成 utt−(R/ρ)ut=c2uxx，会造成能量增长，符号错误。

μn=(n+1/2)π/b，右边导数引入 μncosh(μna)。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

上下混合边界决定半整数正弦；右边给导数，归一化要对双曲函数求导。

逐步解答

由 Y(0)=0,Y′(b)=0，得 Yn=sinμny，μn=(n+1/2)π/b，n≥0。在 x 方向，Xn′′−μn2Xn=0，Xn(0)=0，故取 sinhμnx。令

fn=2b∫0bf(s)sinμnsds.
使右边导数恰等于展开后的 f，得到
u(x,y)=∑n=0∞fnsinhμnxμncoshμnasinμny.
求 x 导数并令 x=a 时归一因子完全抵消；其余三边齐次条件成立。

最终答案

u=∑n≥0fnsinh(μnx)sin(μny)/[μncosh(μna)]，fn=2b−1∫0bfsinμnsds。

这一类题的答题套路与易错点＋

可复用步骤

混合齐次边界 → 半整数谱 → 非零通量边归一其导数 → 投影边界数据。

易错点

右边给 ux，分母必须是 μncoshμna，不能用 sinhμna。

两条非零边界的稳态叠加

矩形内 uxx+uyy=0；u(0,y)=Ay(b−y)、u(a,y)=0，u(x,0)=Bsin(πx/a)、u(x,b)=0。求 u。

提示：从哪里入手＋

Ay(b−y) 的正弦系数只含奇数，值为 8Ab2/(n3π3)。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

线性叠加为左边单独非零与底边单独非零两个问题。

逐步解答

令 u=v+w。v 只承担左边 Ay(b−y)，其余三边零；w 只承担底边 Bsin(πx/a)，其余三边零。 左边投影系数

cn=2b∫0bAy(b−y)sinnπybdy=4Ab2[1−(−1)n]n3π3.
于是
v=8Ab2π3∑m=0∞sinh[(2m+1)π(a−x)/b](2m+1)3sinh[(2m+1)πa/b]sin(2m+1)πyb.
底边是单一模态，故
w=Bsinh[π(b−y)/a]sinh(πb/a)sinπxa.
所求为二者相加。四角数据都为零，相互相容；检查 x=0 与 y=0 的非齐次边时另一部分恰为零。

最终答案

u=v+w，其中 v 为上述左边奇数正弦级数，w=Bsinh[π(b−y)/a]sin(πx/a)/sinh(πb/a)。

这一类题的答题套路与易错点＋

可复用步骤

多非零边 → 叠加拆成单边驱动 → 分别选择正交方向 → 最后逐边核对。

易错点

在左边驱动的项里使用 a−x 才能令右边为零；底边驱动要用 b−y。

拉盖尔方程自伴化

将拉盖尔方程 xy″+(1−x)y′+ay=0 化为标准施图姆–刘维尔形式，并确定权函数。

提示：从哪里入手＋

乘 e−x，因为 (xe−x)′=(1−x)e−x。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

找乘子使一、二阶导数合并为一个总导数。

逐步解答

原方程乘 e−x 得 xe−xy″+(1−x)e−xy′+ae−xy=0。前两项恰为

(xe−xy′)′+ae−xy=0.
与 (py′)′−qy+λwy=0 比较，p=xe−x,q=0,λ=a,w=e−x。通常区间为 (0,∞)，在该区间权函数为正。若研究拉盖尔多项式的正交性，还需在零点和无穷远选合适的正则/可积解，不能只靠方程确定全部边界谱。

最终答案

(xe−xy′)′+ae−xy=0；权函数 w=e−x（常数倍等价）。

这一类题的答题套路与易错点＋

可复用步骤

一般二阶方程自伴化 → 乘子使 (μa2)′=μa1 → 读出参数系数为权。

易错点

权函数是参数项的系数，不是导数项 xe−x。

解题思路

导数项提示高斯积分因子。

逐步解答

乘 e−x2 后，

e−x2y″−2xe−x2y′+2ae−x2y=0,
即
(e−x2y′)′+2ae−x2y=0.
取 p=e−x2,q=0,λ=2a,w=e−x2；若坚持用 λ=a，则权写 2e−x2，与前者只差正常数。通常区间为全轴，带权内积 ∫−∞∞e−x2fgdx，边界须选择使积分与边界项合适的解。

最终答案

(e−x2y′)′+2ae−x2y=0；w=e−x2、λ=2a。

易错点

不要把 2a 与 a 的参数选择混用；权允许乘正常数，但须与本征参数一致。

习题 3.4 · 4教材 p.164 / PDF p.173条件 / 勘误

实谱证明与非负谱命题的反例

本征问题 (ky′)′−qy+λρy=0（a<x<b），边界 α1y(a)+α2y′(a)=0、β1y(b)+β2y′(b)=0。题给 k,q,ρ 为非负实函数、边界系数为实常数，要求证明：(1)本征值均为实数；(2)本征值均非负。

读题注意

第二问对任意实 Robin 边界系数声称本征值非负不成立。解析给出 λ=−1 的反例，并列出可保证非负的能量条件。

提示：从哪里入手＋

反例：区间 (0,1)，k=ρ=1,q=0，两端均取 y′−y=0，y=ex 对应 λ=−1。

展开详细解析：思路 · 步骤 · 答案＋

解题思路

用拉格朗日恒等式证明实谱，用能量商检查非负性；第二个命题缺少边界符号条件，原样不成立。

逐步解答

先补标准非退化假设：正则问题需 k>0,ρ>0，每个端点的两边界系数不同时为零；仅写“非负”允许退化，甚至 ρ≡0 会让参数失去谱意义。 (1)对本征函数 y 的方程乘 y¯，减去共轭方程乘 y，在 [a,b] 积分得

(λ−λ¯)∫abρ|y|2dx=−[k(y′y¯−yy¯′)]ab.
实分离边界保证每个端点括号为零：Dirichlet时 y=0；否则 y′ 是实常数乘 y。积分严格正，故 λ=λ¯。 (2)原题“所有实常数边界都使本征值非负”是错误的。取 a=0,b=1,k=ρ=1,q=0，边界 y′(0)−y(0)=y′(1)−y(1)=0。y=ex 非零，满足两边界且 y″−y=0，故对应 λ=−1<0，完全符合原题系数条件。 正确判据来自能量商：
λ=∫ab[k|y′|2+q|y|2]dx−[ky′y¯]ab∫abρ|y|2dx.
Dirichlet或Neumann边界使边界项为零，所以 λ≥0。若两端均为Robin且 α2β2≠0，边界贡献为
k(b)β1β2|y(b)|2−k(a)α1α2|y(a)|2.
例如补上 α1/α2≤0、β1/β2≥0 就可保证非负；更一般的充分必要表述是整个能量二次型非负。不能为了完成证明而删掉原题允许的Robin边界。

最终答案

(1)在标准非退化自伴假设下本征值为实数。(2)原题不成立：y=ex、两端 y′−y=0 给 λ=−1。补充使能量边界贡献非负的条件后，才有 λ≥0。

这一类题的答题套路与易错点＋

可复用步骤

谱性质题 → 先查假设是否足够 → 共轭相减证明实性 → 能量商看符号 → 不足时提供具体反例与正确版本。

易错点

实Robin边界保证自伴与实谱，不自动保证非负谱；积分分部后的边界项不能擅自丢掉。
